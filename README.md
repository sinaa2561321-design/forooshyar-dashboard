# فروش‌یار — نمونه‌کار توسعه وب

یک پنل مدیریت سفارش فارسی و RTL برای نمایش توانایی‌های توسعه وب.

## امکانات
- رابط RTL و فارسی
- طراحی Responsive برای موبایل، تبلت و دسکتاپ
- React + Next.js + TypeScript
- API Route برای دریافت سفارش‌ها
- مدیریت Loading / Error / Empty State
- جست‌وجو و فیلتر سفارش‌ها
- کامپوننت‌های قابل استفاده مجدد
- تست E2E با Playwright
- ساختار مناسب برای توسعه و نگهداری

## اجرا
```bash
npm install
npm run dev
```
سپس `http://localhost:3000` را باز کنید.

## تست
```bash
npx playwright install
npm test
```

> این پروژه یک نمونه‌کار شخصی است و نباید به‌عنوان سابقه شغلی واقعی معرفی شود.
